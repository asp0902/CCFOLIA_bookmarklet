카피바라 4세 입양 안내

초대 링크의 동의를 누르면 코코포리아 룸으로 이동합니다. 주사위, 말 이동, 캐릭터 시트 같은 기본 기능은 모두 코코포리아가 처리하고, 카피바라 4세는 그 위에 확장 기능(서식 채팅, 추가 채팅 패널, 홈 즐겨찾기 등)을 얹습니다.

코코포리아 계정 로그인과 룸 입장 권한은 코코포리아 규칙을 그대로 따릅니다.

방법 1. 확장 프로그램 (권장: 룸에 들어가면 자동 적용)

  1. 저장소 압축 파일(zip)을 받아 압축을 풉니다.
  2. Chrome에서 chrome://extensions를 열고 오른쪽 위 개발자 모드를 켭니다.
  3. 압축해제된 확장 프로그램을 로드합니다를 누르고, 압축 푼 폴더 안의 extension/personal 폴더를 선택합니다.
  4. 초대 링크를 다시 열고 동의를 누르면 코코포리아 룸에 카피바라 기능이 켜진 상태로 입장합니다.

설치 후에는 코코포리아 룸을 열 때마다 자동으로 켜집니다. 자세한 설명은 확장 README를 보세요.

방법 2. 북마클릿 (설치 없이, 룸에 들어갈 때마다 한 번 클릭)

  1. 아래 버튼을 북마크 막대로 끌어다 놓습니다.
  2. 코코포리아 룸에 들어간 뒤 그 북마크를 누르면 카피바라 기능이 켜집니다.
