# 작업 지시서: 플레이룸(웹 공유 화면)을 코코포리아 기본 화면과 맞추기 (사용자 요청, 2026-11-23)

사용자: "웹 공유 플레이룸 페이지와 코코포리아 기본 페이지를 비교해 플레이룸을 수정."
비교 대상(같은 룸 FNxxq2TBw, 메시지 없는 빈 룸): https://ccfolia.com/rooms/FNxxq2TBw (툴킷 없는 기본 화면) vs https://capybara-iv.for-trpg.workers.dev/#room=FNxxq2TBw
추론 세션이 앱 내 브라우저에서 1440×900과 471×863 두 크기로 실측(getComputedStyle·rect). 고칠 곳: prototype/public-handout-relay/public (participant.js·style.css).
원칙: 코코포리아 값을 그대로. 플레이룸 고유 기능(펭귄 버튼, 접속 표시 초록 점, 서식 바, 탭 '+' 없음)은 유지.

## A. 1440×900에서 다른 점 (왼쪽 = 코코포리아, 오른쪽 = 플레이룸)
1. **캐릭터 이름 칸**
   - 코코: 채운 상자 — 감싸는 div 배경 rgba(0,0,0,0.2), padding 4px, 205×40 (x 1113), 그 안 input 197×32, 밑줄 없음, padding 4px 0 5px.
   - 플레이룸: input 205×32에 아래 테두리 0.67px rgba(255,255,255,0.7)(밑줄 모양), 배경 없음, 줄 높이 42.
   → 코코 모양(채운 상자, 밑줄 없음, 40px)으로.
2. **주사위 버튼 줄**: 코코 D4 x=1077(버튼 30×30, padding 3px, 간격 34) / 플레이룸 x=1069(padding 0). → 왼쪽 시작 8px 안쪽으로, padding 3px.
3. **입력부 바탕**: 코코 = div rgb(18,18,18) 위에 form rgba(0,0,0,0.1) / 플레이룸 = form rgb(18,18,18)만. → 같은 겹(조금 더 어두움).
4. **글자 값**
   - 입력칸·이름칸: 코코 16px/23px, letter-spacing 0.15008px, Roboto, Helvetica, Arial, sans-serif / 플레이룸 16px/24px, ls normal, Roboto+"Noto Sans KR".
   - 하단 'Dicebot engine' 줄: 코코 12px/19.92px ls 0.39996px(글 폭 183) / 플레이룸 12px/15px ls normal(171).
   - 헤더 '룸 채팅': 코코 h6 14px/21.98px 700 ls 0.09996px.
   → 코코 값으로(한글 대체 글꼴은 Roboto, Helvetica, Arial 뒤에 두어 영문·숫자 폭이 같게).
5. **하단 줄 위치**: 'Dicebot engine' 글 y — 코코 874 / 플레이룸 859(아래 여백이 더 큼). 입력칸 100px 상자 아래~바닥 간격을 코코와 같게.
6. **상단 바 룸 제목 옆 시스템 이름**: 코코는 제목 뒤에 작은 글씨 '크툴루의 부름 7판'(12px, rgb(238,238,238), ls 0.39996px) / 플레이룸 없음. → 중계 데이터에 다이스봇(시스템) 이름이 있으면 표시, 없으면 GM 쪽에서 실어 보내기(작게).
7. **BGM 표시**: 코코 'BGM01' 'BGM02' 두 칸(재생 중인 칸 파랑) / 플레이룸 'BGM' 하나, 볼륨 슬라이더 위치도 다름(코코 슬라이더가 더 짧고 왼쪽). → 칸 이름·배치를 코코처럼(두 칸).
8. **채팅 목록 스크롤바**: 코코는 목록 오른쪽에 스크롤 트랙이 항상 보임(위·아래 화살표 포함, 밝은 회색) / 플레이룸 안 보임. → 같은 모양(overflow-y: scroll + 같은 폭·색).
9. **서식 바**(플레이룸에만 있음 — 기본 코코엔 없으니 툴킷의 지금 서식 바와 비교): 플레이룸은 옛 상자형 버튼(배경 rgb(40,40,40), 테두리 0.67px rgba(255,255,255,0.1), 30×30)이고 구분선(—)·유지·Sv 등이 없음. 툴킷 서식 바는 #585·#615 뒤 테두리 없는 평평한 버튼 + Aa/⋯ 묶음. → 툴킷 서식 바의 지금 모양·배치로(기능은 플레이룸이 지원하는 것만, 없는 기능 버튼은 넣지 말 것).
10. 탭 줄(메인/정보/잡담): 위치·폭 일치(1105부터 59px씩). 손댈 것 없음.

## B. 471×863(좁은 화면)에서 다른 점
- 코코: 채팅 서랍이 화면 전체를 덮음(맵 안 보임). 헤더 '룸 채팅' 64px, 목록이 화면 대부분, 아래에 탭·이름·주사위·입력칸(약 90px)·Dicebot 줄.
- 플레이룸: 위에 상단 바+맵(BGM·확대 버튼·연필 버튼) 약 380px, 그 아래에 '룸 채팅' 헤더와 채팅. 채팅 목록이 매우 짧고 입력칸이 화면 밖으로 밀림(화면 아래에서 서식 바가 잘림).
- → 좁은 폭에서는 코코처럼 채팅이 전체 화면을 덮게(헤더의 '>|' 버튼으로 접으면 맵). 입력칸·전송이 항상 화면 안에.

## 진행
- 수정 전후를 같은 두 크기에서 나란히 캡처(docs/img/playroom-parity-1123-*.png)하고, 위 항목별 실측값 표로 보고.
- 메시지가 있는 상태의 줄 모양(아바타·이름·시각·본문 간격, 구분선, 다이스 결과 색)도 테스트 룸에서 같은 메시지로 비교해 차이를 이 문서 아래에 추가 후 수정(이번 비교 룸은 비어 있어 못 봄).
- participant.js·style.css는 Worker 정적 파일 → 실제 반영은 Worker 재배포 필요(사용자 승인). 대기 중인 #577·#598·#604와 함께 한 번에.
