# 기능 반영 표 (확장 / 북마클릿 / 플레이룸)

살아 있는 문서: PR마다 갱신. 기준일 2026-11-24, main `5023f18`(loader 0.3.225, format-sync 0.1.156, chat-panel 0.5.65, Worker `51a9d918` 이후).

## 읽는 법
- 칸 값: **됨** / **안 됨**(사유) / **해당 없음**(사유).
- 확인 수준: `실측` 실제 룸에서 확인 · `주소` 실제 배포 주소에 코드 반영 확인 · `모의` 모의 페이지 테스트만 · `미확인`.
- 북마클릿 열은 코드로 판정했다. 로더 카탈로그(`src/capybara-toolkit-loader.js`)는 확장·북마클릿이 같은 목록을 쓴다. `alwaysOn`이 아닌 스크립트는 툴킷 패널에서 **각자 켜야 함**: 서식 편집 도구, 테마 커스텀, BGM/Alarm, 로그 패키지, 핸드아웃. 확장 전용은 `chrome.*`·릴레이·identity를 쓰는 것으로, 웹 공유(릴레이)·Drive·홈 즐겨찾기 일부·Roll20 읽기·X 기록이 해당한다.
- 플레이룸 열의 근거는 `prototype/public-handout-relay/public/participant.js`와 테스트 이름이다.
