# 핸드아웃 Google Drive 동기화 — 준비 안내 (사용자용)

이 기능은 내가 GM으로 만든 핸드아웃 원본을 내 Google Drive에 자동으로 올리고 받아서, 여러 PC가 같은 핸드아웃을 쓰게 합니다. Drive의 변경 이력(버전)으로 예전 내용을 보고 되돌릴 수도 있습니다.

- 카피바라 **확장 프로그램 전용**입니다. 북마클릿에는 이 기능이 없습니다.
- 권한은 `drive.file` 하나만 씁니다. 이 기능이 만든 파일만 볼 수 있고, Drive의 다른 파일은 보지 않습니다.
- Drive에는 이런 폴더가 생깁니다: `카피바라IV 핸드아웃 / 룸제목 (룸id) / 핸드아웃id.json`, 그리고 `rooms.json`. Drive 웹에서 직접 열어 보고, 파일 버전 기록도 볼 수 있습니다.

## 한 번만 하는 준비 (약 10분)

확장 ID는 모든 PC에서 같습니다: `dhogfdgmikpinakhcofcddmcmoaenpjc`
(확장 manifest에 공개키가 들어 있어서 PC가 달라도 바뀌지 않습니다. chrome://extensions에서 '카피바라 4세'의 ID와 같은지 확인하세요.)

1. **Google Cloud 프로젝트**: https://console.cloud.google.com 에서 프로젝트를 하나 만듭니다(이름은 자유).
2. **Drive API 켜기**: 'API 및 서비스 → 라이브러리'에서 **Google Drive API**를 찾아 '사용'을 누릅니다.
3. **OAuth 동의 화면**: 'API 및 서비스 → OAuth 동의 화면'을 엽니다.
   - 사용자 유형: **외부**
   - 앱 이름·이메일: 자유롭게 입력
   - 범위: `.../auth/drive.file` 추가
   - 테스트 사용자: **본인 구글 계정** 추가(게시하지 않고 '테스트' 상태로 두면 됩니다)
4. **클라이언트 ID 만들기**: '사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID'를 누릅니다.
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 리디렉션 URI: `https://dhogfdgmikpinakhcofcddmcmoaenpjc.chromiumapp.org/`
   - 만들면 나오는 **클라이언트 ID**(…apps.googleusercontent.com)만 복사합니다. 클라이언트 보안 비밀번호는 쓰지 않으니 어디에도 붙여 넣지 마세요.
5. **붙여 넣고 연결**: 코코포리아에서 확장 아이콘을 눌러 **웹 공유 화면**을 엽니다. '핸드아웃 Google Drive 동기화' 칸에 클라이언트 ID를 붙여 넣고 **[연결]**을 누릅니다.
   - 구글 로그인·동의 창이 뜨면 **본인이 직접** 로그인하고 허용합니다.
   - 클라이언트 ID는 이 브라우저의 확장 저장소에만 저장되고, 코드·로그에는 남지 않습니다.

## 다른 PC에서

- 확장을 설치(또는 새로고침)한 뒤 5번만 하면 됩니다. 클라이언트 ID는 같은 것을 씁니다.
- 처음 연결할 때 방향을 고릅니다: **동기화(최신 우선, 기본)** / PC → 드라이브 / 드라이브 → PC.
  동기화 전까지 이 룸의 핸드아웃은 브라우저에 백업됩니다.
- 브라우저를 다시 켜면 로그인 토큰이 사라져 조용히 다시 받습니다. 그래도 안 되면(구글 로그인 만료, 동의 화면 '테스트' 상태의 7일 승인 만료 등) 설정 탭 상태 줄이나 방향 선택 창의 **[다시 연결]**을 누르면 구글 로그인 창이 열립니다.

## 쓰는 법

- **자동**: 핸드아웃을 저장·삭제·순서 변경하면 몇 초 뒤 Drive에 올라갑니다. 삭제한 것은 Drive 휴지통으로 갑니다(영구 삭제 아님). 룸에 들어가거나 '전체 룸'을 열 때 Drive에서 받습니다.
- **변경 이력**: 핸드아웃 편집 화면 또는 줄 우클릭 메뉴의 '변경 이력'에서 날짜별 버전을 보고 되돌립니다. 되돌리기 전의 내용도 버전으로 남습니다.
  - Drive는 오래된 버전을 자동으로 정리합니다(30일 또는 100개). 꼭 남길 버전은 **'이 버전 보관'**을 누르세요.
- **충돌**: 두 PC에서 같은 핸드아웃을 동시에 고치면 최신 쪽이 남습니다. 진 쪽은 '보관' 버전으로 남고 토스트로 알려 줍니다.
- **연결 해제**: 웹 공유 화면의 [연결 해제]를 누르면 이 브라우저의 토큰을 지웁니다. Drive 파일은 그대로 남습니다.

## 문제가 생기면

- 오프라인·권한 만료·용량 초과로 실패해도 이 PC의 핸드아웃과 플레이어 공유(Firebase)는 그대로입니다. 설정 탭 상태 줄에 마지막 동기화 시각과 오류 사유(로그인 만료 · Drive API 꺼짐 · 권한 범위 · 네트워크 등)가 표시됩니다.
- '액세스 차단됨'·'redirect_uri_mismatch'가 뜨면 4번의 리디렉션 URI(끝의 `/` 포함)와 확장 ID가 같은지 확인하세요.
- 테스트 사용자에 본인 계정이 없으면 로그인이 막힙니다(3번).
