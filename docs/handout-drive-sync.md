# 작업 지시서: 핸드아웃 Google Drive 자동 동기화 + 변경 이력 (사용자 결정, 2026-11-17)

사용자: "자동 동기화가 꼭 필요 → Google Drive. Drive에도 변경 이력을 남길 수 있는지?"
대체하는 것: 전체 룸 핸드아웃 2차 1번(다른 PC 목록 — Worker 커스텀 토큰 방식)은 **하지 않음**. Drive 동기화가 그 역할.

## 범위
- 대상: 내가 GM으로 만든 핸드아웃 원본(제목·본문·비밀·GM 메모·이미지·폴더·순서·권한표) + 룸 목록(룸 id·제목). 받은 사본(inbox, _remote)은 제외.
- 확장 프로그램 전용(chrome.identity). 북마클릿 경로에는 없음 — 화면에 한 줄.
- 플레이어 공유(Firebase inbox·팝업)는 지금 그대로. Drive는 GM 원본의 백업·PC 간 동기화.

## 인증 (비밀값 금지)
- chrome.identity + OAuth, 범위는 **drive.file 하나만**(이 앱이 만든 파일만 접근). 다른 Drive 파일 못 봄.
- OAuth 클라이언트 ID는 사용자가 Google Cloud에서 직접 만들어 넣음 — 설정 칸(웹 공유 팝업 또는 GM 도구 설정의 '핸드아웃 동기화')에 붙여넣기. 클라이언트 비밀·토큰·키를 저장소·문서·로그·ntfy에 넣지 말 것. 세션이 사용자 대신 로그인·발급하지 말 것.
- 사용자 안내서(docs/handout-drive-setup.md)를 같이 작성: Cloud 프로젝트 → OAuth 동의 화면(테스트 사용자 = 본인) → 클라이언트 ID(Chrome 확장, 확장 ID) → 붙여넣기 → '연결' 버튼. 압축 해제 확장의 ID가 PC마다 달라지지 않게 하는 방법(manifest key) 포함 여부 확인해 한 줄.
- 연결 해제 버튼(토큰 폐기).

## 저장 구조 (보이는 폴더 — 사용자가 Drive에서 직접 이력 확인 가능)
- `카피바라IV 핸드아웃/{룸제목 (룸id)}/{핸드아웃id}.json` + `rooms.json`(색인). 이미지는 같은 폴더에 파일로(본문엔 참조).
- 올리기: 저장(편집·삭제·순서·폴더·권한표) 뒤 디바운스(예: 5초)로 그 핸드아웃 파일만 갱신. 삭제는 Drive 휴지통으로(영구 삭제 금지).
- 받기: 룸 입장·'전체' 열 때·수동 '지금 동기화'. 로컬에 없는 것 추가, 양쪽 다 있으면 updatedAt 최신 우선.
- 충돌: 양쪽 모두 마지막 동기화 이후 바뀌었으면 덮어쓰기 전에 진 쪽을 이력에 남김(아래) + 토스트.

## 변경 이력
1. Drive 자체 버전: 같은 파일을 갱신(files.update)하면 Drive가 버전을 쌓음(자동 정리: 30일/100개). 중요한 시점은 keepRevisionForever 로 고정 가능 — '이 버전 보관' 버튼(파일당 상한 200).
2. 툴킷 이력 보기: 핸드아웃 편집창(또는 줄 우클릭)에 '변경 이력' → revisions.list 로 날짜 목록, 고르면 그 버전 내용 미리보기 + '이 버전으로 되돌리기'(되돌리기 전에 현재본도 버전으로 남음).
3. 충돌로 진 쪽·삭제된 것도 이력/휴지통에서 복구 가능.

## 안전
- 실패(오프라인·권한 만료·용량)해도 로컬 저장·Firebase 공유는 영향 없음. 상태 줄(설정 탭): 마지막 동기화 시각 / 오류.
- 첫 연결 시 방향 선택: '이 PC → Drive 올리기' / 'Drive → 이 PC 받기' / '합치기(최신 우선)'. 기본 합치기, 덮어쓰기 전 로컬 백업 키.
